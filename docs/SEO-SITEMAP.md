## Skabelon for hver side og artikel
1. Dokumenteret målgruppe og ét primært søgebehov.
2. Unik title tag (sigte ca. 50–60 tegn, men prioriter klarhed), unik meta description (sigte ca. 140–160 tegn), én H1.
3. Direkte svar på spørgsmålet først, derefter H2/H3, konkrete eksempler og nuancer.
4. Faglig gennemgang og forfatterinformation; skeln mellem personlige erfaringer, dokumenteret viden og fortolkning.
5. 2–5 kontekstuelle interne links til beslægtede artikler og relevant ydelse; én naturlig CTA.
6. Canonical, Open Graph/Twitter metadata, 1200x630 preview, beskrivende billedfilnavn og alt-tekst.
7. Article/Person/Organization/BreadcrumbList schema hvor det matcher sidens faktiske indhold. Ingen misvisende FAQ rich-results løfter.
8. Mobiltilgængelighed, Core Web Vitals, XML sitemap, robots.txt og indekseringskontrol.
9. Opdateringsdato, redaktionel kvalitetssikring, faktatjek, samtykke for klienthistorier.
