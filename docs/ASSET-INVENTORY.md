# Mindset Fitness – assetinventar

## Skal indsamles
| Type | Foretrukket format | Status |
| --- | --- | --- |
| Logo master | SVG | Afventer |
| Logo transparent | PNG | Afventer |
| Favicon | SVG/PNG | Afventer |
| Portræt Marco | JPG/WebP original | Afventer |
| Foredragsbilleder | JPG/WebP original | Afventer |
| Video intro | MP4/WebM original | Afventer |
| Bogforside(r) | JPG/PNG høj opløsning | Afventer |
| Open Graph previews | 1200x630 WebP/JPG | Afventer |
| Brandfont | Navn, licens, evt. WOFF2 | Afventer |

## Regler
- Originalfiler bevares uændret i separat originalmappe, når de modtages.
- Weboptimerede varianter navngives beskrivende.
- Tilføj kilde, ophavsret, alt-tekst og brugstilladelse.
- Video skal have posterbillede, undertekster hvis tale, og mobiltilpasset indlæsning.
- Ingen fontfiler deles uden verificeret licens.
